# EspControl Integration

<img src="https://raw.githubusercontent.com/jtenniswood/espcontrol-integration/main/brand/icon.png" alt="EspControl" width="128" height="128">

Installation, upgrade behavior, troubleshooting, and development instructions
are maintained in the [repository guide](../../README.md).

The [catalog contract](../../docs/catalog-contract.md) defines the native action
and legacy HTTP compatibility boundary. ESPHome remains the owner of native
device communication and entities; this integration provides discovery,
selection metadata, sensor mirrors, and controls that forward to their native source.
