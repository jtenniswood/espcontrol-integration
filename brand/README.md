# EspControl branding

`icon.png` and `logo.png` use the supplied EspControl artwork unchanged: an
864 × 864 transparent PNG with a blue house and white touch symbol. The same
artwork is used on light and dark backgrounds.

Keep these files identical to the copies in
`custom_components/espcontrol/brand/`. The integration copies are included in
HACS downloads and release packages, and Home Assistant serves them as local
brand images. The root copies are available for repository branding and the
README displayed by HACS.

Home Assistant supports bundled brand images from 2026.3 onward. No manifest
icon setting is needed.
See the [Home Assistant brand image documentation](https://developers.home-assistant.io/docs/core/integration/brand_images/)
and [HACS brand asset requirements](https://hacs.xyz/docs/publish/integration/#brand-assets).
